A small plugin I made in a bit over an hour to fix an issue that has been bugging me since forever :xdd:, just a simple way to find the settings page of any plugin without having to search through the openplanet settings table. Should be very useful if you have TONS of plugins installed, like me :xdd:

Disabled plugins are highlighted in red, and every search result has icon buttons for toggling or reloading the plugin directly from the menu.

Press `Ctrl + K` to show Openplanet and open the search menu. Both keys can be changed from the plugin's Hotkey settings.

Use Up/Down to select a plugin, Left/Right to choose its name, toggle, or reload action, and Enter to activate the highlighted target.
